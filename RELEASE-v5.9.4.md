# Cyrius Stream Control v5.9.4

## Временное отключение потоков

Поток можно временно отключить через `disabled=true` без удаления конфигурации.

- Кнопка ⏻ в строке потока переключает отключение/включение.
- Для выбранных каналов доступны массовые кнопки **Отключить** и **Включить**.
- Зеркальные потоки меняются на всех включённых CDN.
- Назначенные потоки меняются только на своём основном CDN.
- Перед изменением создаётся backup конфигурации.
- Повторная команда не создаёт лишний PUT или backup.
- Режим Static/On demand и остальные поля сохраняются.
- Включение не запускает автоматическую проверку источников.
