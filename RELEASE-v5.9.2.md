# Cyrius Stream Control v5.9.2

## Массовый импорт M3U

В разделе **Потоки** добавлена кнопка **Импорт M3U**.

Панель разбирает пары:

```text
#EXTINF:...,Название канала
URL
```

Сохраняются только:

- `title` — отображаемое название канала;
- `input` — следующая строка URL.

Метаданные `tvg-id`, `tvg-name`, `group-title`, `tvg-logo`, `tvg-chno` не переносятся в конфигурацию Flussonic.

Системное имя генерируется автоматически (`TVP 1 HD` → `TVP_1_HD`, `Первый канал HD` → `Pervyy_kanal_HD`). Перед импортом доступен предпросмотр. Уже существующие системные имена по умолчанию пропускаются; перезапись включается отдельной галочкой.

Импорт поддерживает обе модели размещения: зеркало на всех включённых CDN или назначение на один CDN. Сетевые операции запускаются только после ручного нажатия кнопки импорта.
