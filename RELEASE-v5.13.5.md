# Cyrius Stream Control v5.13.5

Hotfix интерфейса ручной проверки источников.

- Добавлен отдельный выбор сервера в разделе «Источники»: ВСЕ / конкретный CDN.
- «Проверить все сейчас» при ВСЕ проверяет все включённые CDN.
- При выборе конкретного CDN кнопка запускает проверку только этого сервера.
- Таблица и счётчики фильтруются по выбранному CDN.
- Переключение сервера само проверку не запускает: source-check остаётся полностью ручным.
- Сохранена совместимость с Flussonic 23 и трактовка отсутствующего `static` как Static.
