# Cyrius Stream Control v5.9.1

## Источники только по запросу

- Удалён фоновый планировщик `source-health-monitor`.
- Значения `SOURCE_CHECK_ENABLED=true` и `SOURCE_CHECK_SECONDS` в старом `.env` больше не запускают автоматический обход input.
- Полная проверка запускается только кнопкой **Проверить все сейчас**.
- Для каждой сохранённой строки добавлена кнопка **Проверить** — проверяется выбранный поток на выбранном CDN.
- Добавление, удаление и повышение приоритета input больше не запускает скрытую повторную проверку.
- После изменения input старый результат удаляется; свежий результат появляется только после ручного запуска.

Размещение каналов и гибридный/зеркальный режим из v5.9 сохранены без изменений.
