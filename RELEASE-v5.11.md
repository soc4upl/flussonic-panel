# Cyrius Stream Control v5.11.2

## Постепенная миграция каналов по CDN

- Новый неразрушающий планировщик `План 100/CDN`.
- Автоматическое заполнение свободной ёмкости с учётом уже назначенных каналов.
- Выбор любой пачки из плана без изменения Flussonic.
- Новый безопасный workflow `Перенести сейчас` с отдельным Dry Run.
- Target CDN всегда создаётся/обновляется и повторно проверяется до удаления старых копий.
- Backup перед изменением target и каждым удалением.
- Assigned фиксируется после успешной проверки target; оставшиеся при частичной ошибке дубли видны как extras и не восстанавливаются зеркальной синхронизацией.
- Миграция блокируется, если хотя бы один включённый CDN нельзя проверить.
- Параллелизм миграции ограничен тремя каналами.
- `cluster_ingest` не используется и не добавляется.

## Безопасный порядок запуска

Сначала мигрируйте 2–3 тестовых канала и проверьте их через существующий клиентский LB URL. Только после подтверждения маршрутизации peer/LB переходите к пачкам по 100 каналов.
