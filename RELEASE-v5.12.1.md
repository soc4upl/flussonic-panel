# Cyrius Stream Control v5.12.1

## Постпроверка миграции

После каждой миграции в разделе **Размещение → История миграций** доступна кнопка **✓ Проверить**. Проверка вручную читает текущую конфигурацию на CDN и сравнивает её с ожидаемым результатом миграции.

Показываются:

- наличие канала на целевом CDN;
- лишние копии на остальных CDN;
- недоступные серверы;
- совпадение конфигурации target со снимком до миграции;
- состояние placement в панели.

Для проблемного канала кнопка **Исправить** сначала открывает Dry Run, после чего можно безопасно повторить миграцию. Из окна проверки также доступны карточка канала и rollback всей миграции.

Проверка выполняется только по запросу пользователя и не создаёт фонового мониторинга источников или потоков.
