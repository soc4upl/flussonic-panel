# Cyrius Stream Control v5.9.3

## On demand / Static

- В таблице потоков для каждого канала появились быстрые кнопки **On demand** и **Static**.
- Для отмеченных каналов появились массовые кнопки **On demand** и **Static**.
- M3U-импорт позволяет сразу выбрать режим новых каналов.
- В зеркальном режиме изменение применяется ко всем включённым CDN.
- В гибридном распределённом режиме назначенный канал меняется только на назначенном CDN.
- Перед изменением режима конфигурация каждого существующего потока сохраняется в backup.
- Если потока нет на целевом CDN, операция возвращает ошибку и не создаёт пустой поток.
