# Cyrius Stream Control v5.13.1

## Точный набор немигрированных каналов на один CDN

В разделе «Размещение» добавлен ручной набор: выберите целевой CDN, введите количество и нажмите «Выбрать N». Панель выберет следующие N каналов, которые всё ещё находятся в режиме Mirror. Это именно добавочное количество: уже назначенные на CDN каналы не вычитаются из N.

Пример: осталось 300 зеркальных каналов, на CDN-5 уже назначено 40. Ввести 230 → выбрать CDN-5 → «Выбрать 230». После успешной миграции на CDN-5 будет 270 назначенных, а 70 каналов останутся Mirror.

Сам выбор ничего не меняет во Flussonic. Реальные изменения выполняются только через «Перенести сейчас» → Dry Run → «Применить изменения».
