# Cyrius Stream Control v5.13.2

## Telegram: поток `error/offline`

Добавлен лёгкий фоновый монитор runtime-статуса потоков Flussonic.

- Не использует `ffprobe`.
- Не открывает input/source URL.
- Читает только обычный `/streamer/api/v3/streams` на включённых CDN.
- Реагирует на явные состояния `error`, `offline`, `failed`, `dead` и их варианты.
- `ondemand waiting` считается нормальным состоянием.
- `disabled` не считается аварией.
- В Гибридном режиме Assigned-поток контролируется только на назначенном CDN.
- В Зеркальном режиме состояние контролируется отдельно на каждой зеркальной копии.
- Telegram/Webhook отправляется один раз при переходе в ошибку, без повторного спама.
- После восстановления можно получить отдельное `🟢 Поток восстановлен`.
- Настраиваются интервал 15–3600 секунд и 1–5 подтверждений ошибки подряд.
- Кнопка `Проверить статусы` запускает ручной опрос без проверки source URL.

По умолчанию рекомендуются 30 секунд и 2 подтверждения подряд.
