# Cyrius Stream Control v5.13.0

## Глобальный режим панели

В **Настройки** добавлены две явные модели работы:

- **Зеркальный** — все включённые CDN считаются зеркалами; раздел Размещение и Assigned-интерфейс скрыты.
- **Гибридный** — включены постепенное распределение, Assigned, миграции, rollback и постпроверка.

Смена режима не удаляет сохранённые назначения.

## Потоки → ВСЕ

В селектор серверов добавлен `ВСЕ · объединённый список`. Потоки с одинаковым системным именем объединяются в одну строку, а рядом показывается фактическое присутствие по CDN. При частично недоступных серверах список строится по доступным CDN с предупреждением.

В режиме ВСЕ порядок потоков не меняется; для drag-and-drop нужно выбрать конкретный сервер. Preview, диагностика и карточка канала автоматически используют реальный CDN, где найден поток.
